# Отчет по домашнему заданию: Оптимизация инференса и перенос моделей

## Введение
В данной работе исследовали оптимизацию инференса нейронных сетей и перенос моделей на различные платформы. Основная цель - сравнить производительность PyTorch моделей с их оптимизированными версиями в форматах ONNX и TensorRT на примере классификации изображений.

Проект включает в себя:
- Обучение ResNet-18 для разных размеров входных изображений
- Конвертацию моделей в ONNX и TensorRT форматы
- Тестирование производительности
- Анализ влияния размера батча и изображений на скорость инференса

---

**Платформы для оптимизации:**
1. **PyTorch** - базовая реализация
2. **ONNX Runtime** - кроссплатформенный инференс
3. **TensorRT** - NVIDIA GPU оптимизация

---

## Конвертация моделей

**Цель:** Конвертировать обученные PyTorch модели в ONNX и TensorRT форматы.

**ONNX конвертация:**
- Использован стандартный экспорт PyTorch → ONNX
- Поддержка динамических размеров батча
- Оптимизация для GPU инференса

**TensorRT конвертация:**
- Torch-TensorRT компиляция напрямую из PyTorch
- FP32 precision

**Размеры файлов:**
- PyTorch (.pth): ~43 MB
- ONNX (.onnx): ~43 MB  
- TensorRT (.trt): 33-62 MB (зависит от размера)

   - Использование GPU памяти (MB)
   - **Использование CPU памяти** (MB)

3. **Дополнительные метрики:**
   - Эффективность использования GPU
   - Анализ оптимального размера батча

## Анализ загруженности видеокарты

**Основные выводы по GPU утилизации:**

1. **TensorRT показывает лучшую загруженность GPU:**
   - Малые батчи (1): 85-95% 
   - Большие батчи (16+): 95-99% 
   - **Оптимальная эффективность: 95%+**

2. **PyTorch:**
   - Малые батчи (1): 65-80%
   - Большие батчи (16+): 90-98%
   - Недогрузка при малых батчах указывает на возможность оптимизации

3. **ONNX показывает плохую загруженность:**
   - Все размеры батчей: 10-30%
   - Указывает на неэффективную работу с GPU

**Определение оптимального батча:**
- **Для TensorRT:** оптимальный батч = 8-16 (баланс время/картинку vs загруженность)
- **Для PyTorch:** оптимальный батч = 16-32 (максимальная загруженность без переполнения памяти)
- **Для ONNX:** все батчи неэффективны в текущей конфигурации

## Проблемы с ONNX Runtime

**Возможные причины низкой производительности ONNX:**
1. **Проблемы с GPU ускорением:** неэффективная работа с CUDA операциями
2. **Неэффективная конвертация операций:** некоторые операции PyTorch могли быть неоптимально переведены
3. **Версионная несовместимость:** проблемы между версиями ONNX Runtime и CUDA
4. **Отсутствие специфичных оптимизаций** для архитектуры RTX 3060

## Сравнительный анализ

### Преимущества каждой платформы:

**PyTorch:**
- + Простота использования и отладки
- + Стабильная производительность
- + Полная совместимость с исходной моделью
- + Хорошая стабильность (низкое стд. отклонение)
- - Высокое потребление GPU памяти

**ONNX:**
- + Кроссплатформенность
- + Минимальное потребление GPU и CPU памяти
- - Крайне низкая производительность в данной конфигурации
- - Высокая нестабильность времени выполнения
- - Плохая загруженность GPU (10-30%)
- - Сложности с оптимизацией

**TensorRT:**
- + Лучшая производительность (до 2.57x ускорения)
- + Высочайшая стабильность (наименьшее стд. отклонение)
- + Оптимальная загруженность GPU (95-99%)
- + Наилучшее время инференса на картинку
- + Умеренное потребление памяти
- - Ограничена экосистемой NVIDIA
- - Сложность настройки и оптимизации
